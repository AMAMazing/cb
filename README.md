# ⚡ cb — Cline Headless Clipboard Bridge

Zero-dependency OpenAI-compatible clipboard bridge and XML multi-tool batch compiler for Cline in GitHub Codespaces. Automatically fetches the latest rules from `AMAMazing/cline-x/main/unified_rules.txt`.

## Quick Start (Run in any Codespace terminal)

Run with npx:
`npx -y amamazing/cb`

Or run directly via curl:
`curl -sL https://raw.githubusercontent.com/amamazing/cb/main/cline-bridge.js | node`

## Cline Settings

- **API Provider:** `OpenAI Compatible`
- **Base URL:** `http://localhost:4000/v1`
- **API Key:** `any-key`
- **Model ID:** `cline-headless-bridge`
